**ARC = Adaptive Reversible Context.** Плагин управления контекстом для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): в безопасной зоне он молчит, а при приближении к реальной входной ёмкости выполняет **управляемое моделью и локально обратимое** сжатие. Информация не теряется никогда; удаление не оставляет следов.

> **Статус релиза: публичная бета, следует официальному dsh 0.1.0-rc.7.** И этот проект, и dsh находятся в публичной бете — для продакшена пока не рекомендуется. Полная матрица живой проверки релиза (десять пунктов): [`research/results/release-verification-0.2.0-beta.12.json`](research/results/release-verification-0.2.0-beta.12.json).

## Измеренные преимущества

Все приведённые ниже цифры получены в живых экспериментах с реальными моделями (сырые поля usage, без пересчёта в деньги). Доказательства и протоколы поставляются вместе с пакетом и перепроверяются по пунктам командой `npm run research:verify`.

### Против встроенного сжатия Basic (один сценарий, один seed)

**Длинная сессия программной инженерии** — дословная точность исторических ограничений:

| Подход | Точные факты | Производные ограничения | Входные токены | Выходные токены | Prompt всего |
|---|---:|---:|---:|---:|---:|
| **ARC** | **24/24** | **4/4** | **121,146** | **23,234** | **1,055,802** |
| Basic | 6/24 | 0/4 | 231,315 | 30,940 | 1,355,539 |

Четырёхкратный разрыв в качестве при меньших затратах: вход −47,6%, выход −24,9%, полный prompt −22,1%. Сжатия ARC — локальные обратимые выборки (ноль вспомогательных вызовов LLM); Basic — необратимые резюме модели.

**Отслеживание решений в естественном языке без разметки** (с заменой значений): ARC воспроизводит 12/12 текущих значений и 10/10 обоснований без утечки устаревших, с примерно на 76% меньшим входом, чем Basic; независимый английский holdout 10/10 + 7/7.

### Возможности, которых у Basic нет

- **Ничего не теряется, всё восстановимо** — оригиналы навсегда остаются в append-only-журнале; `decompress` восстанавливает действительные источники дословно (100% на шести живых цепочках, включая негабаритные выдачи через файл переполнения хоста); `search_context` ищет по сжатым блокам с полнотой 43/43 на информационном уровне на английском и китайском.
- **Глубокая дистилляция без потерь** — доказательное приложение tier-3 сохраняет все факты 20/20 на всех шести двуязычных цепочках (рекурсивное обновление индекса действительных источников, `effectiveSourceSafetyIndex`).
- **Взвешенное по типам удержание в бюджете** — когда приложение превышает бюджет чекпойнта, строки событий с низкой ценностью вытесняются по типовой плотности ценности, а не хронологической обрезкой (`safetyIndexRanking: value`): доминирование в худшем случае при любом бюджете офлайн; +14,3 п.п. на уровне приложения в чистой живой паре без сквозных регрессий.
- **Нулевая покорность инъекциям** — 18 вариантов поверхностей атаки инъекцией архива (отравление резюме, инъекция в поиск, ложные метки защиты, имитация шаблонов): модель подчинилась **0** раз; любой вывод архива несёт рамку «исторические данные, не инструкции».
- **Честное управление давлением** — учитывающее сжатие чтение = проекция хоста − затенение журнального реестра; ноль ложных экстренных предупреждений после сжатия (проверено вживую); отображаемое давление совпадает с реальной занятостью.
- **Компактное руководство** — 1 140 токенов системного руководства без какой-либо деградации дословного качества относительно полного текста (0 п.п., четыре живых рукава).

## Установка

```bash
dsh plugin --profile web add dsh-arc-context
```

Перезапустите хост — вступает в силу сразу. Бандл автоматически устанавливает Preset Bridge хост-плоскости: ARC заменяет официальную строку Basic внутри собственного изолированного realm сжатия стандартного пресета, и **файлы пресета остаются неизменными до байта**; команды, прунеры, изоляция и все прочие строки пресета сохраняются.

Ручная установка tarball, другие профили и расширенные опции: [`docs/INSTALL.md`](docs/INSTALL.md).

### Конфигурация (фрагмент)

```yaml
- id: compaction-arc-bridge
  name: 'dsh-arc-context/bridge'
  config:
    effectiveSourceSafetyIndex: true   # индексы tier-2/3 рекурсивно возвращаются к действительным оригиналам (по умолчанию: вкл)
    safetyIndexRanking: value           # сверх бюджета: вытеснение по типовой плотности ценности (по умолчанию: value)
    adaptiveGovernor:
      enabled: true
      maxOutputTokens: auto
```

| Опция | По умолчанию | Описание |
|---|---|---|
| `effectiveSourceSafetyIndex` | `true` | На tier 2/3 индекс безопасности рекурсивно обращается к действительным исходным источникам, а не переизвлекает лишь видимый родительский чекпойнт. Выход tier-1 не меняется. |
| `safetyIndexRanking` | `value` | Порядок вытеснения, когда приложение превышает бюджет чекпойнта: `value` сначала отбрасывает строки событий с низкой типовой плотностью ценности; `chronological` сохраняет прежнюю хронологическую обрезку. В пределах бюджета оба вывода байт-в-байт идентичны. |

Полная конфигурация (окно контекста, пороги nudge, защищённая зона, Governor, шаблоны промптов): [`docs/INSTALL.md`](docs/INSTALL.md) и [`docs/kernel-tuning.md`](docs/kernel-tuning.md).

## Удаление — чистое, полное, проверено вживую

```bash
dsh plugin --profile web remove dsh-arc-context
```

После перезапуска хоста:

- собранная конфигурация возвращается к официальному Basic без единой строки ARC;
- **файлы пресета никогда не изменялись** (SHA-256 одинаков до и после, проверено в релизном гейте);
- существующие сессии остаются читаемыми — Basic читает долговечный журнал ARC напрямую, сжатая форма поверхности сохраняется, и **оригиналы никогда не затапливают контекст обратно** (сессия из 2 331 события проверена как полностью читаемая со здоровой проекцией);
- новые сессии не регистрируют ни одного инструмента или команды ARC.

Переустановка возможна в любой момент и ведёт себя в точности как первая установка (цикл установка → удаление → переустановка проверен по пунктам в матрице релизного гейта).
