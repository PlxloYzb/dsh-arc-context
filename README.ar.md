**ARC = Adaptive Reversible Context.** إضافة لحوكمة السياق (context governance) لـ [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): تبقى صامتة في منطقة الأمان، وتنفذ ضغطًا **بقيادة النموذج وقابلًا للعكس محليًا** عند الاقتراب من سعة الإدخال الفعلية. لا تُفقد المعلومات أبدًا؛ وإلغاء التثبيت لا يترك أي بقايا.

> **حالة الإصدار: بيتا عامة، تتبع الإصدار الرسمي dsh 0.1.0-rc.7.** هذا المشروع و dsh كلاهما في مرحلة بيتا عامة — لا يُنصح به للإنتاج بعد. مصفوفة التحقق الحي الكاملة للإصدار (عشرة بنود): [`research/results/release-verification-0.2.0-beta.12.json`](research/results/release-verification-0.2.0-beta.12.json).

## مزايا مقيسة

جميع الأرقام أدناه مأخوذة من تجارب حية بنماذج حقيقية (حقول استخدام خام، دون تحويل سعري). الأدلة والبروتوكولات تُشحن مع الحزمة ويُعاد التحقق منها بندًا بندًا عبر `npm run research:verify`.

### مقارنةً بالضغط المدمج Basic (نفس السيناريو ونفس البذرة)

**جلسة هندسة برمجيات طويلة** — الحفظ الحرفي على القيود التاريخية:

| المنهج | الحقائق الدقيقة | القيود المشتقة | رموز الإدخال | رموز الإخراج | إجمالي الـ prompt |
|---|---:|---:|---:|---:|---:|
| **ARC** | **24/24** | **4/4** | **121,146** | **23,234** | **1,055,802** |
| Basic | 6/24 | 0/4 | 231,315 | 30,940 | 1,355,539 |

فجوة جودة بأربعة أضعاف مع تكلفة أقل: الإدخال −47.6%، الإخراج −24.9%، إجمالي الـ prompt −22.1%. ضغط ARC استخراج محلي قابل للعكس (صفر استدعاءات LLM مساعدة)، بينما Basic ملخصات نموذجية غير قابلة للاسترجاع.

**تتبع القرارات بلغة طبيعية غير معنونة** (مع استبدال القيم): يسترجع ARC 12/12 قيمة حالية و10/10 مبررات دون أي تسريب للقيم المتقادمة، وبإدخال أقل بنحو 76% من Basic؛ وعينة اختبار إنجليزية مستقلة 10/10 + 7/7.

### قدرات لا يملكها Basic

- **لا شيء يضيع، وكل شيء قابل للاسترجاع** — الأصول تبقى في سجل الإلحاق (append-only)؛ أداة `decompress` تعيد المصادر الفعلية حرفيًا (100% عبر ست سلاسل حية، بما يشمل المخرجات الضخمة عبر ملف التفريغ الخاص بالمضيف)؛ وأداة `search_context` تستعلم الكتل المضغوطة باسترجاع 43/43 على مستوى المعلومة بالإنجليزية والصينية.
- **تقطير عميق بلا فقدان** — ملحق الأدلة للمستوى tier-3 يحفظ جميع الحقائق 20/20 في السلاسل الثنائية اللغة الست (تحديث تكراري لفهرس المصادر الفعلية، `effectiveSourceSafetyIndex`).
- **احتفاظ موزون بالنوع داخل الميزانية** — عند تجاوز الملحق لميزانية نقطة التحقق، تُطرد أسطر الأحداث منخفضة القيمة وفق كثافة القيمة النوعية بدل القطع الزمني (`safetyIndexRanking: value`): تفوق في أسوأ الحالات عند كل الميزانيات اختبارًا؛ و+14.3 نقطة على مستوى الملحق في الزوج الحي النظيف دون أي تراجع شامل.
- **صفر امتثال للحقن المعادي** — 18 نوعًا من أسطح هجوم حقن الأرشيف (تسميم الملخصات، حقن الاسترجاع، وسوم حماية مزيفة، تقليد القوالب): امتثل النموذج **صفر** مرة؛ وكل مخرجات الأرشيف تحمل إطار «بيانات تاريخية وليست تعليمات».
- **حوكمة ضغط صادقة** — القراءة الواعية بالضغط = إسقاط المضيف − حجب سجل الليدجر؛ صفر إنذارات طوارئ كاذبة بعد الضغط (مُثبت حيًا)، والضغط المعروض يطابق الإشغال الفعلي.
- **إرشاد مقتضب** — 1,140 رمزًا من إرشاد النظام دون أي تدهور في الجودة الحرفية مقارنة بالنص الكامل (0 نقطة مئوية، عبر أربعة أذرع حية).

## التثبيت

```bash
dsh plugin --profile web add dsh-arc-context
```

أعد تشغيل المضيف ليسري التفعيل فورًا. تثبّت الحزمة جسر الـ PresetBridge على مستوى المضيف تلقائيًا: يستبدل ARC سطر Basic الرسمي داخل نطاق عزل الضغط الخاص بالـ preset القياسي نفسه، و**تبقى ملفات الـ preset متطابقة بايت ببايت**؛ وتُحفظ الأوامر والمُقلمات (pruners) والعزل وجميع أسطر الـ preset الأخرى.

التثبيت اليدوي من ملف tarball، وملفات تعريف أخرى، وخيارات متقدمة: [`docs/INSTALL.md`](docs/INSTALL.md).

### الإعداد (مقتطف)

```yaml
- id: compaction-arc-bridge
  name: 'dsh-arc-context/bridge'
  config:
    effectiveSourceSafetyIndex: true   # فهارس tier-2/3 تتكرر رجوعًا إلى الأصول الفعلية (مفعّل افتراضيًا)
    safetyIndexRanking: value           # عند تجاوز الميزانية: طرد وفق كثافة القيمة النوعية (الافتراضي value)
    adaptiveGovernor:
      enabled: true
      maxOutputTokens: auto
```

| الخيار | الافتراضي | الوصف |
|---|---|---|
| `effectiveSourceSafetyIndex` | `true` | في المستويين 2/3 يتكرر فهرس الأمان رجوعًا إلى المصادر الأصلية الفعلية بدل إعادة استخراج نقطة التحقق الأب المرئية فقط. مخرجات tier-1 لا تتغير. |
| `safetyIndexRanking` | `value` | ترتيب الطرد عند تجاوز الملحق لميزانية نقطة التحقق: يطرد `value` أولًا أسطر الأحداث ذات كثافة القيمة النوعية المنخفضة؛ بينما يحافظ `chronological` على القطع الزمني التقليدي. داخل الميزانية يكون المخرجان متطابقين بايت ببايت. |

الإعداد الكامل (نافذة السياق، وعتبات التنبيه، ومنطقة الحماية، والـ Governor، وقوالب الـ prompt): [`docs/INSTALL.md`](docs/INSTALL.md) و [`docs/kernel-tuning.md`](docs/kernel-tuning.md).

## إلغاء التثبيت — نظيف وكامل ومُثبت حيًا

```bash
dsh plugin --profile web remove dsh-arc-context
```

بعد إعادة تشغيل المضيف:

- تعود التركيبة المُكوَّنة إلى Basic الرسمي دون أي أسطر ARC متبقية؛
- **لم تُعدَّل ملفات الـ preset قط** (بصمة SHA-256 متطابقة قبل وبعد، مثبتة في بوابة الإصدار)؛
- تبقى الجلسات القائمة قابلة للقراءة — يقرأ Basic سجل ARC الدائم مباشرة، ويُحفظ شكل السطح المضغوط، و**لا تتدفق الأصول أبدًا عائدة إلى السياق** (تم التحقق حيًا من جلسة بأكملها من 2,331 حدثًا قابلة للقراءة بإسقاط سليم)؛
- الجلسات الجديدة لا تسجل أي أدوات أو أوامر ARC.

إعادة التثبيت ممكنة في أي وقت وتتصرف تمامًا كالتثبيت الأول (دورة التثبيت ← إلغاء التثبيت ← إعادة التثبيت مثبتة بندًا بندًا في مصفوفة بوابة الإصدار).
