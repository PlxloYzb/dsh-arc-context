# Roadmap

## Beta / RC

- clean-profile install and rollback matrix across additional DSH versions;
- sanitized raw-evidence release artifact;
- public opt-in canaries on code engineering and free-form conversations;
- workload-level regression reports using only raw input/output/cache-read fields.

## Stable criteria

- no known durable-log corruption or unrecoverable replacement path;
- no negative token projection across supported host token meters;
- documented provider/model compatibility table;
- multiple independent real-workload reports showing ARC is at least Basic-equivalent in quality;
- stable configuration and migration contract.

New predictors or learned policies are out of scope until evidence shows the
current no-history formula is insufficient.
