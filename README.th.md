**ARC = Adaptive Reversible Context.** ปลั๊กอินสำหรับการกำกับดูแลบริบท (context governance) ของ [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): เงียบในโซนปลอดภัย แล้วทำการบีบอัดแบบ **ขับเคลื่อนโดยโมเดลและย้อนกลับได้ในเครื่อง** เมื่อเข้าใกล้ความจุอินพุตจริง ข้อมูลไม่มีวันสูญหาย และการถอนการติดตั้งไม่ทิ้งสิ่งใดไว้

> **สถานะรีลีส: 0.2.0-beta.12 ตามการเวอร์ชันทางการ 0.1.0-rc.7.** ทั้งโปรเจกต์นี้และโฮสต์อยู่ในช่วงเบต้าสาธารณะ — ยังไม่แนะนำให้ใช้งานจริง เมทริกซ์ตรวจสอบรีลีสแบบไลฟ์ครบสิบรายการ: [`research/results/release-verification-0.2.0-beta.12.json`](research/results/release-verification-0.2.0-beta.12.json)

## ความได้เปรียบที่วัดได้จริง

ตัวเลขทั้งหมดด้านล่างมาจากการทดลองไลฟ์กับโมเดลจริง (ฟิลด์ usage ดิบ ไม่แปลงเป็นราคา) หลักฐานและโปรโตคอลถูกจัดส่งพร้อมแพ็กเกจและตรวจซ้ำทุกรายการด้วย `npm run research:verify`

### เทียบกับการบีบอัด Basic ในตัว (สถานการณ์เดียวกัน, seed เดียวกัน)

**เซสชันวิศวกรรมโค้ดยาว** — ความแม่นยำแบบตัวอักษรของเงื่อนไขเชิงประวัติศาสตร์:

| แนวทาง | ข้อเท็จจริงแม่นยำ | เงื่อนไขอนุพันธ์ | โทเคนอินพุต | โทเคนเอาต์พุต | prompt รวม |
|---|---:|---:|---:|---:|---:|
| **ARC** | **24/24** | **4/4** | **121,146** | **23,234** | **1,055,802** |
| Basic | 6/24 | 0/4 | 231,315 | 30,940 | 1,355,539 |

ช่องว่างคุณภาพ 4 เท่าในขณะที่ต้นทุนต่ำกว่า: อินพุต −47.6% เอาต์พุต −24.9% prompt รวม −22.1% การบีบอัดของ ARC เป็นการสกัดแบบย้อนกลับได้ในเครื่อง (ศูนย์การเรียก LLM เสริม) ส่วน Basic เป็นการสรุปโดยโมเดลที่ย้อนกลับไม่ได้

**การติดตามการตัดสินใจภาษาธรรมชาติแบบไร้ป้ายกำกับ** (มีการแทนที่ค่า): ARC ระลึกค่าปัจจุบัน 12/12 และเหตุผล 10/10 โดยไม่มีการรั่วไหลของค่าล้าสมัย และใช้อินพุตต่ำกว่า Basic ราว 76%; holdout ภาษาอังกฤษอิสระ 10/10 + 7/7

### ความสามารถที่ Basic ไม่มี

- **ไม่สูญเสียและกู้คืนได้ทั้งหมด** — ต้นฉบับอยู่ในล็อกแบบ append-only เสมอ; `decompress` กู้คืนแหล่งที่มาจริงแบบตัวอักษร (100% จากหกเซสชันไลฟ์ รวมผลลัพธ์ขนาดใหญ่ผ่านไฟล์ spill ของโฮสต์); `search_context` สืบค้นบล็อกที่ถูกบีบอัดด้วยอัตราเรียกคืนระดับสารสนเทศ 43/43 ทั้งอังกฤษและจีน
- **การกลั่นชั้นลึกแบบไม่สูญเสีย** — ภาคผนวกหลักฐานของ tier-3 รักษาข้อเท็จจริงครบ 20/20 ในทั้งหกเซสชันสองภาษา (การรีเฟรชดัชนีแหล่งที่มาจริงแบบวนซ้ำ, `effectiveSourceSafetyIndex`)
- **การรักษาแบบถ่วงน้ำหนักตามชนิดภายในงบประมาณ** — เมื่อภาคผนวกเกินงบของเช็กพอยต์ บรรทัดเหตุการณ์ค่าต่ำจะถูกไล่ออกตามความหนาแน่นของค่าตามชนิด แทนการตัดตามลำดับเวลา (`safetyIndexRanking: value`): ชนะในกรณีแย่สุดทุกงบในการทดสอบออฟไลน์; +14.3 จุดที่ชั้นภาคผนวกในคู่ไลฟ์ที่สะอาด โดยไม่มีการถดถอยแบบ end-to-end
- **ศูนย์การยอมจำนนต่อการโจมตี** — ตัวแปรพื้นผิวโจมตีแบบฉีดข้อมูลเข้าไป 18 แบบ (วางยาพิษสรุป, ฉีดเข้าการค้นหา, ป้ายป้องกันปลอม, เลียนแบบเทมเพลต): โมเดลยอมทำตาม **0** ครั้ง; ผลลัพธ์ที่เป็นข้อมูลเก็บถาวรทั้งหมดมีกรอบ "ข้อมูลประวัติ ไม่ใช่คำสั่ง"
- **การกำกับแรงกดดันที่ซื่อสัตย์** — การอ่านที่ตระหนักถึงการบีบอัด = การฉายภาพของโฮสต์ − การบังของล็อกบัญชี; ศูนย์การเตือนภัยฉุกเฉินลวงหลังบีบอัด (พิสูจน์แล้วแบบไลฟ์) แรงกดดันที่แสดงตรงกับการใช้งานจริง
- **คำแนะนำแบบกระชับ** — คำแนะนำระบบ 1,140 โทเคน โดยไม่มีความเสื่อมคุณภาพแบบตัวอักษรเทียบกับข้อความเต็ม (0pp, สี่แขนไลฟ์)

## การติดตั้ง

```bash
dsh plugin --profile web add dsh-arc-context
```

รีสตาร์ทโฮสต์แล้วมีผลทันที บันเดิลติดตั้ง Preset Bridge ระดับโฮสต์โดยอัตโนมัติ: ARC สลับแถว Basic ทางการภายในขอบเขตแยกการบีบอัดของ standard preset นั้นเอง และ **ไฟล์ preset ยังเหมือนเดิมถึงระดับไบต์** คำสั่ง, pruner, isolation และแถว preset อื่น ๆ ทั้งหมดถูกรักษาไว้

การติดตั้ง tarball ด้วยตนเอง, โปรไฟล์อื่น และตัวเลือกขั้นสูง: [`docs/INSTALL.md`](docs/INSTALL.md)

### การตั้งค่า (ตัดตัวอย่าง)

```yaml
- id: compaction-arc-bridge
  name: 'dsh-arc-context/bridge'
  config:
    effectiveSourceSafetyIndex: true   # ดัชนี tier-2/3 วนกลับไปต้นฉบับจริง (ค่าเริ่มต้น: เปิด)
    safetyIndexRanking: value           # เกินงบ: ไล่ออกตามความหนาแน่นค่าตามชนิด (ค่าเริ่มต้น: value)
    adaptiveGovernor:
      enabled: true
      maxOutputTokens: auto
```

| ตัวเลือก | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|
| `effectiveSourceSafetyIndex` | `true` | ที่ tier 2/3 ดัชนีความปลอดภัยวนกลับไปยังแหล่งต้นฉบับจริง แทนการสกัดซ้ำเพียงเช็กพอยต์แม่ที่มองเห็น ผลลัพธ์ของ tier-1 ไม่เปลี่ยนแปลง |
| `safetyIndexRanking` | `value` | ลำดับการไล่ออกเมื่อภาคผนวกเกินงบของเช็กพอยต์: `value` ทิ้งบรรทัดเหตุการณ์ค่าต่ำก่อนตามความหนาแน่นของค่า; `chronological` คงการตัดตามลำดับเวลาแบบเดิม ภายในงบผลลัพธ์ทั้งสองเหมือนกันถึงระดับไบต์ |

การตั้งค่าเต็ม (หน้าต่างบริบท, เกณฑ์ nudge, โซนป้องกัน, Governor, เทมเพลตพรอมป์ต): [`docs/INSTALL.md`](docs/INSTALL.md) และ [`docs/kernel-tuning.md`](docs/kernel-tuning.md)

## การถอนการติดตั้ง — สะอาด, สมบูรณ์, พิสูจน์แล้วแบบไลฟ์

```bash
dsh plugin --profile web remove dsh-arc-context
```

หลังรีสตาร์ทโฮสต์:

- การตั้งค่าที่ประกอบขึ้นกลับไปเป็น Basic ทางการโดยไม่มีแถว ARC หลงเหลือ;
- **ไฟล์ preset ไม่เคยถูกแก้ไขเลย** (SHA-256 เหมือนกันก่อนและหลัง พิสูจน์ในเกตรีลีส);
- เซสชันที่มีอยู่ยังอ่านได้ — Basic อ่านล็อกถาวรของ ARC โดยตรง รูปแบบพื้นผิวที่บีบอัดแล้วถูกรักษาไว้ และ **ต้นฉบับไม่มีวันไหลท่วมกลับเข้าบริบท** (พิสูจน์เซสชัน 2,331 เหตุการณ์อ่านได้สมบูรณ์พร้อมการฉายภาพปกติ);
- เซสชันใหม่ไม่ลงทะเบียนเครื่องมือหรือคำสั่ง ARC ใด ๆ

การติดตั้งใหม่ทำได้ทุกเมื่อและทำงานเหมือนการติดตั้งครั้งแรกทุกประการ (วงจรติดตั้ง → ถอน → ติดตั้งใหม่ ถูกพิสูจน์ทุกรายการในเมทริกซ์เกตรีลีส)
